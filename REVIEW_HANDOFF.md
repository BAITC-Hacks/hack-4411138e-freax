# Передача разработчику и ревьюеру

## Текущее состояние

По запросу пользователя проект переведён в бэкенд-структуру `ayqyn/`. Старые HTML/CSS/JS, runtime vendor и браузерные проверочные скрипты убраны. API, CLI, исходники, наборы данных и исследования сохранены.

- Запуск: `python server.py --port 8765` или `python -m ayqyn.api.server --port 8765`.
- `/` и `/api/health` возвращают JSON; страницы `/?research=...` больше нет.
- Результат: `/api/research/<id>?view=workspace`; источники — в `documents[].paragraphs`, оригинал — через `view=original`.
- [API](docs/API.md), [дизайн фронтенду](docs/FRONTEND_HANDOFF.md), [структура](docs/architecture.md).

Перед изменением создан проверенный ZIP текущих локальных исходников, веб-файлов, тестов и документации: `output/backups/before-backend-layout-20260923T120624Z.zip`. Он содержит незакоммиченные правки команды и лицензии прежнего vendor. Архив локальный, игнорируется Git и не раздаётся API; указатель — `output/backups/latest-backend-layout.json`.

Remote refs обновить не удалось: запись `.git/FETCH_HEAD` запрещена окружением. Перенос основан на локальном дереве. Коммит, push и слияние входящего интерфейсного коммита не выполнялись.

## Передача фронтендеру

Реализовать сценарий по `docs/FRONTEND_HANDOFF.md` на реальных ответах API. Просмотр сохранённого результата не должен делать POST. Сервер локальный, CORS для произвольного frontend origin отсутствует; proxy/same-origin описан в `docs/API.md`.

Различать прочитанное, проверенное агентом и подтверждённое аналитиком. Backend endpoints сохранения ручной оценки и экспорта отсутствуют: frontend должен реализовать их локально либо согласовать отдельное расширение API.

## Следующая работа по качеству

1. Диагностический тест выделения и сопоставления функций на небольшом достаточном контексте без эталонных ответов.
2. При фиксированном коде — отдельное сравнение настроек рассуждения.
3. Отдельная оценка исправления вытеснения семантических кандидатов RRF на сохранённых векторах.
4. Адресное чтение цитат, завершение начатых сопоставлений, затем новый сопоставимый R8/R9.

Не менять одновременно модель, парсер, поиск и поведение агента. Перестройка файлов не считается улучшением анализа.
