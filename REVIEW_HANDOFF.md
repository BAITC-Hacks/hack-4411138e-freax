## Передача фронтендеру

Реализовать сценарий по `docs/FRONTEND_HANDOFF.md` на реальных ответах API. Просмотр сохранённого результата не должен делать POST. Сервер локальный, CORS для произвольного frontend origin отсутствует; proxy/same-origin описан в `docs/API.md`.

Различать прочитанное, проверенное агентом и подтверждённое аналитиком. Backend endpoints сохранения ручной оценки и экспорта отсутствуют: frontend должен реализовать их локально либо согласовать отдельное расширение API.
