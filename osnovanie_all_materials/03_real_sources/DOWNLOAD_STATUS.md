# Скачанные оригиналы

- original_pdfs/risk_2021.pdf — 6 страниц; официальный раздел Казахтелекома «Система управления рисками», 2021.
  Источник: https://ar2021.telecom.kz/ru/download/risk-management-system.html
- original_pdfs/report_2022.pdf — 189 страниц; полный интегрированный годовой отчет Казахтелекома за 2022 год.
  Источник: https://ar2022.telecom.kz/assets/files/KT2022_rus.pdf
  Для сопоставления участников управления рисками откройте страницу 121 PDF (счет от первой страницы файла).

Оба файла скачаны без изменения оригинального содержимого. Проверены открытие PDF, число страниц и извлечение текста.
Остальные внешние материалы представлены ссылками, их полные файлы не включены.
Документы организатора из Google Docs не скачаны. Перед использованием загрузите соответствующие оригиналы.
Пара 2021/2022 имеет разный объем: один раздел и полный отчет. При сравнении ограничивайте предмет анализа системой управления рисками.
Это публичные корпоративные отчеты, не полностью размеченный набор положений. Юридическая реорганизация и потеря функций по ним не доказаны.
