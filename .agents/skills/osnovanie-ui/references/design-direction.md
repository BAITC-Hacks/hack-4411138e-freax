# Дизайн «Основание»

Актуальный frontend реализует корпоративное направление Казахтелекома и умеренный glassmorphism. Оригинальный пользовательский SVG хранится в assets/kazakhtelecom-logo.svg, пропорции и цвета сохраняются; светлая подложка обязательна в тёмной теме. Нет CSS-фильтров логотипа, эмодзи, внешних шрифтов или runtime CDN.

Токены находятся в analyze.css. Светлый фон #F4F7FB, тёмный #0B1220, тёмная поверхность #131F30, брендовый синий #0085CF. Цвет обычного синего текста/кнопок скорректирован до #006EAB ради контраста; в dark акцент #68C5FA. Glass применяется к навигации, шапке и drawer; для неподдерживаемого backdrop-filter есть непрозрачный fallback. Документы и таблицы на плотной поверхности. Движение 160–220 ms, reduced motion соблюдается.

Основной сценарий: загрузка → анализ → вкладки (подразделения/функции/риски/заключение) → drawer с двумя документами → оценка/комментарий → экспорт. API поддерживает лишь пару DOCX. Не показывать поддержку PDF/Excel, комплектов, промежуточных этапов, владельцев функций или языка ответа, пока backend этого не возвращает.

UI-строки и ошибки в i18n.js (ru/kk/en), динамические числа и даты через Intl. Переключение языка не меняет файлы, анализ, фильтры, отзывы. Цитаты и модельные данные не переводятся молча. preferences.js применяется до CSS, хранит только язык и тему, не документы и ключи.

Lucide 1.47.0 (ISC) подключён выбранными локальными ESM-модулями. Лицензия vendor/lucide/LICENSE, реестр vendor/README.md. Иконки 18–20 px, stroke 1.8. Исходный код 21st.dev не копировался.

Рабочие файлы: analyze.html / analyze.css / analysis.js / i18n.js / preferences.js / icons.js. Для новых assets расширять явный allowlist server.py. Практикум index.html остаётся независимым. Проверять пять ширин 360/390/768/1024/1440, оба оформления, три языка, длинные имена, клавиатуру и скачанный отчёт.
