## MCP для каждого участника

Актуальный сервис — **21st MCP**. Репозиторий [Magic MCP](https://github.com/21st-dev/magic-mcp) описывает его замену и совместимый переходник. Не устанавливать старые конфиги вслепую.

Официальные источники:
- [Настройка 21st](https://21st.dev/mcp)
- [Каталог](https://21st.dev/community/components)
- [Документация Codex MCP](https://developers.openai.com/codex/mcp)
- [Навыки Codex](https://developers.openai.com/codex/skills)

Для поиска и чтения компонентов достаточно официального read-only endpoint:

```text
https://21st.dev/api/mcp/readonly
```

Если сервер `twentyfirst` ещё не настроен в Codex:

```powershell
codex mcp add twentyfirst --url https://21st.dev/api/mcp/readonly
```

Команда может сразу запустить OAuth. Завершить вход и согласие в браузере своего аккаунта. Если конфигурация уже есть, но вход не завершён:

```powershell
codex mcp login twentyfirst
```

Состояние регистрации проверять через `codex mcp get twentyfirst`. После подключения проверить доступные инструменты в новой сессии или после переподключения: наличие конфига не доказывает успешную авторизацию или получение компонентов.

Альтернатива OAuth — личный ключ из 21st MCP и конфигурация с `--bearer-token-env-var API_KEY_21ST`; это альтернативный способ регистрации, не дополнительный сервер. Не помещать ключ в репозиторий, README, примеры URL или вывод инструментов.

Права и лимиты зависят от аккаунта. Каталог описывает ограниченное число установок для бесплатных аккаунтов. Hosted AI generation — отдельная возможность; для адаптации компонента своим Codex она не обязательна. Не покупать подписку автоматически.

## Работа без авторизованного MCP

Сайт предоставляет read-only WebMCP: `search_21st_components`, `read_21st_page_markdown`, `get_21st_agent_setup`. Использовать только реально объявленные инструменты страницы. Доступны описания, авторство, зависимости и лицензия карточки; это не означает получение полного исходного кода.

Публичных превью достаточно для выбора направления и собственной реализации. Содержимое рабочих документов не нужно отправлять в 21st: поиск описываем общими словами, например «file upload», «data table», «evidence detail panel».

## Как вызвать командный навык

Открыть Codex в корне репозитория и написать:

> Используй $osnovanie-ui. Улучши загрузку двух редакций и таблицу результатов по выбранным референсам 21st.dev. Сохрани существующие обработчики, реальные данные и доказательства. Проверь desktop и mobile.

Навык находится в `.agents/skills/osnovanie-ui/`; обычная автоматическая загрузка навыков разрешена. Если текущая сессия ещё не обнаружила его, открыть новую сессию в репозитории либо явно попросить прочитать SKILL.md.
